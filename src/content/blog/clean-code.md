## Clean Code ဆိုတာဘာလဲ

Clean Code ဆိုတာ လူတစ်ယောက်ဖတ်လိုက်တာနဲ့ ချက်ချင်းနားလည်နိုင်တဲ့ Code ကို ဆိုလိုတာဖြစ်ပါတယ်။

### အခြေခံမူဝါဒများ

**၁။ နာမည်ပေးခြင်း (Naming)**

Variable နဲ့ Function နာမည်တွေကို အဓိပ္ပာယ်ရှိရှိ ပေးပါ။

```javascript
// မကောင်းတဲ့ နာမည်
const d = new Date();

// ကောင်းတဲ့ နာမည်
const currentDate = new Date();
```

**၂။ Function တွေကို သေးငယ်အောင် ရေးပါ**

Function တစ်ခုက အလုပ်တစ်ခုပဲ လုပ်သင့်ပါတယ်။ Function တွေကို သေးငယ်အောင်ထားပြီး တစ်ခုချင်းစီက ရှင်းလင်းတဲ့ ရည်ရွယ်ချက်တစ်ခုပဲ ရှိသင့်ပါတယ်။

**၃။ မှတ်ချက် (Comments) နည်းအောင်ထားပါ**

Code ကိုယ်တိုင်က ရှင်းလင်းနေရင် Comment မလိုပါဘူး။ Comment လိုအပ်နေတယ်ဆိုရင်တော့ Code ကို ပိုရှင်းအောင် ပြန်ရေးသင့်ပါတယ်။
