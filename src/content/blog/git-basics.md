## Git ဆိုတာဘာလဲ

Git ဆိုတာ Version Control System (VCS) တစ်ခုဖြစ်ပြီး ကိုယ့်ရဲ့ Code တွေကို Version အလိုက် ခြေရာခံပြီး စီမံခန့်ခွဲနိုင်အောင် ကူညီပေးတဲ့ Tool တစ်ခုပါ။

### အသုံးအများဆုံး Commands များ

**Repository စတင်ဖန်တီးခြင်း**

```bash
git init
git clone <url>
```

**ပြောင်းလဲမှုများ သိမ်းဆည်းခြင်း**

```bash
git add .
git commit -m "commit message"
```

**Remote နဲ့ ချိတ်ဆက်ခြင်း**

```bash
git push origin main
git pull origin main
```

Git ကို ကျွမ်းကျင်စွာ အသုံးပြုတတ်ခြင်းဟာ Developer တစ်ယောက်ရဲ့ အခြေခံအကျဆုံး ကျွမ်းကျင်မှုတစ်ခု ဖြစ်ပါတယ်။
