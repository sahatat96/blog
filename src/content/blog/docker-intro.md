## Docker ဆိုတာဘာလဲ

Docker ဆိုတာဟာ ကိုယ့်ရဲ့ ဆော့ဖ်ဝဲလ် (Software) တွေကို တည်ဆောက်တဲ့အခါမှာ လိုအပ်တဲ့ Tools တွေ အားလုံးကို **Container** လို့ခေါ်တဲ့ သေတ္တာလေးငယ် တစ်ခုတည်းမှာ စုပြုံပြီး Run လို့ရအောင် ဖန်တီးပေးတဲ့ နည်းပညာတစ်ခု ဖြစ်ပါတယ်။

### ဘာကြောင့် Docker ကို သုံးသင့်တာလဲ?

၁။ **"ငါ့စက်မှာတော့ အလုပ်လုပ်တယ်" ပြဿနာ ဖြေရှင်းခြင်း** - ဆော့ဖ်ဝဲလ်ရေးသူတွေ မကြာခဏ ကြုံတွေ့ရလေ့ရှိတဲ့ Development စက်မှာ အလုပ်လုပ်ပြီး Server ပေါ်ရောက်ရင် အလုပ်မလုပ်တော့တဲ့ ပြဿနာကို Docker ရဲ့ Container စနစ်နဲ့ အလွယ်တကူ ဖြေရှင်းနိုင်ပါတယ်။
၂။ **ပေ့ါပါးသွက်လက်ခြင်း** - Virtual Machine (VM) တွေလို OS သီးသန့်ကြီးတစ်ခုလုံး တင်စရာမလိုတဲ့အတွက် Memory (RAM) နဲ့ နေရာယူမှု အလွန်သက်သာပါတယ်။
၃။ **လုံခြုံရေးနဲ့ အခြားများစွာ** - တခြား App တွေနဲ့ လုံးဝ ရောထွေးမှုမရှိဘဲ ယုံကြည်စိတ်ချစွာ Run နိုင်ပါတယ်။

နောက်ပိုင်း သင်ခန်းစာတွေမှာတော့ Docker Commands တွေကို လက်တွေ့အသုံးပြုနည်း ဆက်လက်လေ့လာသွားပါမယ်။
